# Zero Discrete Local Assistant

واجهة محادثة محلية مبنية على OpenCode وOllama، دون رسوم API عند استخدام النماذج المحلية.

شغّل Start-Assistant.cmd ثم افتح http://127.0.0.1:4096 . يبقى الجهاز مشغلاً أثناء الاستخدام.
النموذج الافتراضي Qwen3.5 4B يدعم الصور والأدوات. نموذج Qwen3-Coder 30B مخصص للكود وأثقل على كرت 8GB؛ لا يدعم الصور.
اتصال خادم Studio الرسمي تم التحقق منه. الأدوات المسموحة حاليًا هي الاستكشاف وقراءة السكربتات وحالة Studio فقط؛ أدوات التعديل والرفع غير متاحة للمساعد في هذه الإعدادات.
ملخص المشروع في PROJECT-HANDOFF.md. الملفات الكبيرة تبقى في مسار المشروع الأصلي ولا تُنسخ إلى Git.
راجع طلبات تنفيذ الأوامر والتعديل قبل قبولها. لا توجد مفاتيح سحابية مضمنة.

## التحقق المنفذ
- خادم الواجهة أعاد حالة healthy وHTTP 200.
- النموذج قرأ README عبر أداة القراءة فعلًا.
- أنشأ ملف Luau تجريبيًا وتحققنا أن محتواه return { status = "ok" }.
- اتصال MCP الرسمي ظهر connected. لم ننفذ تعديلًا في اللعبة بهذا المساعد.
- النموذج الأكبر لا يصبح جاهزًا إلا بعد اكتمال تنزيله وظهوره في قائمة Ollama.

## حدود مهمة
هذه إعدادات تشغيل لمشاريع مفتوحة المصدر وليست نموذجًا جديدًا مدربًا خصيصًا. لا ضمان لدقة القرارات أو سلامة المحتوى؛ المراجعة البشرية ضرورية.
إرفاق ZIP لا يعني قدرة النموذج على فهم كل محتوياته دفعة واحدة؛ اطلب منه فهرسة الملفات وفحصها على دفعات.
على كرت 8GB النموذج 4B أنسب للتفاعل الخفيف والصور؛ 30B قد يستخدم الرام ويكون أبطأ. لا تشترِ ترقية قبل قياسه على عملك الفعلي.
بعد استنساخ هذا المجلد من GitHub شغّل Install.ps1 لتنزيل البرامج والنموذج، ثم Start-Assistant.cmd.
